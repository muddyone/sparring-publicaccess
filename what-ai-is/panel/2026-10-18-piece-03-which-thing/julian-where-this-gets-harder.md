# Julian: essay 03, 'Where this gets harder'

**Verdict: it reads as the author's position, but the last sentence lands weakly. It repeats the previous paragraph's point that the builder decides the shape, almost word for word, so the paragraph closes on an echo instead of an extension. The "set out below" reference works but is loose. Three edits.**

1. Current: "Chalmers's account is the base I build from, but he built it around"
   Proposed: "I take Chalmers's account as my base, but he built it around"
   Reason: "build from" followed by "built it" is a jingle. Opening on "I take" also makes the turn to the author's own view clear from the first words.

2. Current: "Chalmers allows for this"
   Proposed: "He allows for this"
   Reason: this is the third "Chalmers" in a short span. The pronoun is unambiguous here, and the citation stays where it is.

3. Current: "What doesn't blur is what follows in practice: the rules for honest presentation set out below apply however you count, and whoever builds the system decides its shape, by choosing what memory is shared and what is sealed off."
   Proposed: "Two things don't blur. The rules for honest presentation, set out in the next section, apply however you count. And the shape is still the builder's choice, now made agent by agent: which notes each one keeps, and which record they all share."
   Reason: the old clause restates the previous paragraph's "design choice, made by whoever builds the assistant… shared memory… sealed-off". The new version moves that point into the multi-agent setting using this paragraph's own material (notes of their own, a shared project record), so it adds to the earlier point instead of repeating it. It also cuts the clumsy "what… is what". "In the next section" is exact: the rules are the four-item list there, while "below" could point anywhere. Splitting into short sentences gives the position its weight, and it holds up read aloud.

Not changed: the "**Where this gets harder.**" label works, and the middle sentence about multi-agent systems is concrete and earns its length. No facts or citations were changed, and no files were edited.
