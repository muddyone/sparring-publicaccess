# Spar records

A **spar** is one run of the SPARRING ceremony: two roles with deliberately disjoint evidence
bases argue a single claim to convergence or to a recorded non-convergence, with challenges held
to *artifact-or-dismissed*. The methodology is in [`framework/`](../../framework/).

These are records of ceremonies run on **SPARRING's own claims**. They are published for the
reason the framework exists: a method that only publishes the runs it won is not showing its
method. Each record is verbatim — including the rounds where the framework's own position lost,
and the runs that never converged.

## How to read one

The **iteration log** is the evidence. A round records each role's `agree:` signal, so a
disagreement that persists is visible rather than smoothed away. Two things worth looking for:

- **Where the framework's own position lost.** In the record above, the Challenger showed the
  premortem's active ingredient is *prospective hindsight* — a certainty framing, not
  adversariality — which made the original "SPARRING is the premortem's enforced generalization"
  inaccurate genealogy. That finding survived into the revised text.
- **The residual claims section.** Each record ends by naming what remains *internally consistent
  but externally unvalidated* — the claims argued structurally and not yet measured. That list is
  a statement of what the framework has **not** earned.
